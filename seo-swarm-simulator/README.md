## 🚀 Quickstart & Installation

Install the package directly via pip:

```bash
pip install seo-swarm-simulator
```

Or clone the repository:

```bash
git clone https://github.com/ADRZZUBAIRI/github-tools.git
cd github-tools/seo-swarm-simulator
pip install -e .
```

## 💻 CLI Usage

Audit any live URL, local PHP template, or static HTML file with task-tailored specialist squads:

```bash
# 1. Single Page High-Priority Reality Audit (13 Specialized Roles)
seo-swarm path/to/page.php --preset single_page_audit

# 2. Local Contractor & Geo Landing Page Audit (18 Specialized Roles)
seo-swarm path/to/local-roofing-page.php --preset local_roofing_audit

# 3. Full Technical & Core Web Vitals Audit (18 Specialized Roles)
seo-swarm path/to/index.php --preset full_technical_audit

# 4. Content Strategy & Information Gain Audit (16 Specialized Roles)
seo-swarm path/to/blog-post.php --preset content_strategy_audit

# 5. Maximum Red-Team Mode (All 62 Roles Run Simultaneously)
seo-swarm path/to/money-page.php --preset full_red_team_all_62
```
