# SEO Swarm Simulator (Multi-Agent Intelligence Engine)

Inspired by the multi-agent consensus architecture of [MiroFish](https://github.com/666ghj/MiroFish), this tool spawns a diverse swarm of autonomous persona agents to audit, stress-test, and critique any website landing page, blog post, or SEO copy prior to deployment.

---

## The Multi-Agent Swarm Personas

1. **Marcus Vance — High-Intent Customer (Commercial Buyer)**:
   - **Role**: Impatient homeowner/business owner seeking urgent estimates on mobile.
   - **Evaluation**: Click-to-call `tel:` action, social proof/reviews, transparent pricing cues, and sub-1s mobile speed.
2. **Dr. Elena Rostova — Senior Technical SEO & Systems Architect**:
   - **Role**: Algorithmic technical auditor.
   - **Evaluation**: Schema.org JSON-LD graph integrity, canonical hierarchy, semantic H1–H3 structure, and title budget (<60 chars).
3. **Sloan Sterling — Direct-Response Copywriter & CRO Specialist**:
   - **Role**: Conversion rate optimization auditor.
   - **Evaluation**: AIDA flow, banning spam buzzwords (*skyrocket*, *game-changer*), high-converting button copy, and cognitive friction in forms.
4. **Synthetix-7 — AI Search Engine Crawler (ChatGPT / Perplexity / SGE)**:
   - **Role**: LLM retrieval & citation engine.
   - **Evaluation**: Low-entropy answer callout blocks, structured tables, verified metrics/percentages, and structured Q&A entities.
5. **Vance Kincaid — Aggressive Competitor Agency Lead**:
   - **Role**: Rival agency looking for weaknesses to exploit.
   - **Evaluation**: Unique value proposition, 100% asset ownership moat, sub-0.8s speed benchmarks, and risk-reversal guarantees.

---

## Usage

Run the swarm on any target page file:

```bash
python swarm_engine.py
```
